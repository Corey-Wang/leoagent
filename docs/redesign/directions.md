# 六个候选与三个完整初稿

共同规格见 `spec.md`，素材与既有设计值见 `brand-spec.md`。六格缩略图：`design-demos/thumbs.html`。三个完整初稿：`dir-1.html`、`dir-2.html`、`dir-3.html`。

## 最佳设计师逻辑

### 候选：精密工作台

来源：Dieter Rams 的功能秩序方法，不复刻特定产品。借用：中性面、网格对齐、控件状态可见、单一操作强调。主角素材是命令和任务事件。骨架：顶栏 → 紧凑状态 → 按事件排列的执行记录 → 固定输入。胆量花在“把执行证据放在对话中心”。form 来自远程执行需要可追溯证据。备选。

### 候选：字面任务

来源：Experimental Jetset 的文字与网格方法，不声称其做过此 App。借用：大字概括任务、严格列对齐、近黑与钴蓝。主角是“等待审批”的文字构图。骨架：任务标题占上半区，操作与文件证据集中在下半区。胆量花在标题尺度。form 来自手机只需先判断“我现在要处理什么”。备选。

## 同媒介现实参照逻辑

### A：清晰工作台（选入完整初稿）

来源：[Things 官方移动界面](https://culturedcode.com/things/)，截图见 `refs/mobile-references-2.jpg`，已查看。借用：单列列表、32px 大标题、16px 正文、缩进分隔线；白色内容为主，蓝色仅用于动作。主角是完整任务、可展开的命令审批。骨架：轻顶栏与项目上下文 → 对话 → 独立审批卡 → 组合输入；会话列表按项目分组。胆量花在留出真实阅读空间，取消现有紫色柔光。form 来自“看完再批准”的手机操作。

### B：夜航控制台（选入完整初稿）

来源：[Linear Mobile 官方 Android/iOS 产品页](https://linear.app/mobile)，截图见 `refs/mobile-references-1.jpg`，已查看。借用：暗色单列列表、细线分区、紧凑元信息、底部工具栏。主角是任务状态与逐步执行证据。骨架：项目条 → 任务标题与状态 → 事件轴 → 紧凑审批面板 → 固定输入；项目会话首页优先展示待处理。胆量花在深色高密度结构，薄荷绿只给核心操作。form 来自离开键盘后处理电脑上的任务，不做终端皮肤。

## 秒数轮盘逻辑

### 候选：硬件面板

来源：Huashu App #01，已查看 `/private/tmp/huashu-design/assets/style-specimens/app/01-hardware-panel.jpg`。借用：石墨底、灰白方形控件、单点信号橙。主角是横向任务状态和可触达操作。骨架：当前任务大字、网格操作、下方事件列表。胆量花在实体按键感。form 来自远程控制工具；因容易让聊天区过于拥挤，作为备选，省略旋钮和无意义仪表读数。

### C：项目工作簿（选入完整初稿）

来源：Huashu east #01 吕敬人书籍设计，已查看 `/private/tmp/huashu-design/assets/style-specimens/east/01-lu-jingren-bookcraft.jpg`。借用：偏心版心、中文衬线标题、右侧窄注释栏、朱色只给关键审批。主角是任务摘要与改动文件的阅读版式。骨架：项目书眉 → 任务标题 → 正文与时间旁注 → 清晰操作 → 输入区。胆量花在中文阅读节奏，其余控件沿用手机语法。form 来自用户在手机阅读 Agent 的过程和结果。降级：平面纸色，无真实纸纤维、装订或翻页效果；不牺牲可读性和触控尺寸。

## 共同输入

LeoAgent 是 Android 原生远程 Agent 工具。用户在手机发送任务，在自己的电脑执行，随时查看过程、审批与结果。主要场景是离开电脑后单手处理任务，不能把连接中断等同于任务停止。

现有实现依据：`android/app/src/main/java/io/leoagent/app/{MainActivity,CodexPane,SettingsActivity,UI}.kt`，`docs/ui-design.md` 和 `README.md`。

- 保留 Agent / 消息 / 设置三个一级入口。项目和会话继续从 Agent 页进入。
- 顶栏保留模型选择、桌面画面、文件差异、更多操作。
- 连接状态与任务状态分别展示；审批、错误和结果未知必须有下一步。
- 输入、添加图片、发送/停止在固定位置；触控目标至少 48px，键盘焦点清晰。
- 四个核心屏：任务对话、项目会话、消息收件箱、连接设置；屏幕之间可以切换，支持展开命令、审批演示、示例消息发送、模型选择、连接/配对弹层。
- 统一设备视口 390 × 844，Android 打孔屏和底部手势区域；设计板可在桌面查看全部屏幕，也可在手机直接操作。
- HTML 原型中的任务、时间、路径和设备名均为界面样例。原生 App 沿用真实数据与回调；验收使用临时数据、隔离服务和确定性 ACP fixture，不调用真实 Agent。

## 内容事实

当前是 Kotlin Views / Material 3 App，不是网页；HTML 仅用于选方向，确认后转入现有 Kotlin 实现。底部为三个 Tab，抽屉提供项目与会话；消息页展示通知；设置页支持连接测试、配对、后台提醒、更新。

主要任务样例：用户请求“给登录表单补上输入校验，并运行测试”；Agent 已完成实现，等待批准执行 `./gradlew testDebugUnitTest`。这是演示中的计划操作，不表示已执行过任何真实测试。

## 各屏 form 五问

| 屏幕 | 角色 | 距离 | 温度 | 容量 | 来自业务的结构 |
|---|---|---|---|---|---|
| 对话 | 核心操作 | 近距离手机 | 冷静、可控 | 一段请求、结果摘要、命令审批、输入区 | 审批必须同时看到命令、项目和动作 |
| 项目会话 | 返回进行中的工作 | 手机 | 有秩序 | 一个项目、三条会话、创建入口 | 按项目组织会话与状态，避免误投任务 |
| 消息 | 判断要不要介入 | 手机 | 简短、明确 | 待处理优先，最近事件其次 | 审批、完成、未知使用文字区分 |
| 设置 | 建立可信连接 | 手机 | 稳定 | 当前电脑、配对入口、系统设置 | 凭据默认隐藏，配对要电脑核对 |

假设：沿用现有名称和 Logo，允许重新探索配色与排版；不增加服务端协议、指标仪表盘或多服务器管理能力。

## 已接通：电脑端可靠执行基础

- `tasks.rs` 实现任务、项目互斥、用户输入和接受回执的同事务写入；相同操作 ID/参数返回原回执，参数变化报冲突。
- 旧 prompt 接口与 `/api/v1/sessions/:id/tasks` 走同一接受入口；不同会话不能绕过同项目互斥。全局活动任务上限通过 `max_active_tasks` 配置，默认 4。
- ACP 发送前持久化派发边界，重启将未派发任务标记失败、已派发无结束记录任务标记未知；未知任务继续占用项目。
- 审批/提问记录持久化，回答有原子接受和回执；区分“决定已接受”“已写入管道”“发送结果未知”，不宣称 Agent 确认收到。
- 取消先进入取消中；20 秒没有完成证据则转为未知，不被晚到的成功覆盖。
- 快照在同一读事务返回最近最多 2000 条事件、当前任务、有效交互及全局游标；增量支持 `after`。新流接口验证数据代数与游标，慢 SSE 客户端不会无限阻塞发送线程。
- 数据目录使用 OS 文件锁防止双启动；旧库第一次迁移前通过 SQLite 备份接口保存一致备份；未来数据库版本拒绝启动。
- Codex 探测与实际执行统一解析 `CODEX_ACP` / PATH；不再固定 Homebrew 路径。旧 ACP 会话恢复失败时明确报错，不悄悄切换新上下文。
- 本机控制 socket 已接入：一次性配对、电脑验证码确认、逐设备摘要凭据、设备列表/撤销；撤销会关闭活动 SSE。服务停止时拒绝新写入并清理自己持有的 ACP 进程组。
- 文件预览令牌改为五分钟有效、绑定设备和目录，并发送 sandbox CSP；手机日志默认本地保存，用户主动上传时脱敏且不再自动上传崩溃日志。
- 异步提问的后续回答先写入 `deferred_prompts`，父任务成功后只派发一次；未知/失败父任务不会自动把回答发送到新回合。
- 增加 `doctor`、SQLite 一致备份、显式停服恢复和数据代数轮换；恢复会撤销旧设备并阻塞恢复点前未完成的后续回答。

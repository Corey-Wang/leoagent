## 本次改变

- 区分本地等待超时、远端错误和通信失败，错误信息包含方法与秒数。
- 仅在 `initialize` 本地超时时，终止并回收本次创建的 Agent 进程，然后用新进程重试一次；两次均失败则明确说明初始化失败、尝试次数和本轮消息未发送。持续故障最多等待约 121 秒。
- 每次初始化保留独立运行记录，日志写入会话、PID、尝试次数和耗时。重连前检查原任务的取消/终止状态，不依据之后创建的任务作判断。
- 不重试 `session/new`、`session/load` 或 `session/prompt`，不自动重发历史失败消息，不更换桌面后端。
- Android 无改动，0.1.7 可使用电脑端返回的错误说明；新增隔离测试已加入 CI。

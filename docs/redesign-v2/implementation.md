# A 静默协作原生落实

用户本轮选择 `A`，见 [direction-approved.md](direction-approved.md)。原生实现已完成。验证结果见下文；此前 HTML 验证与 Android 验收分别记录。

## 当前实现

- 靛蓝动作色与浅/深主题配套颜色，连续白色阅读面、浅灰用户消息、轻量工具面板，Agent 正文保留 Markdown。
- 两行组合输入：文字独占上行；图片、当前 Agent/模型、语音和发送/停止在下行。语音组件支持独立工具行，保留录音与识别流程。
- 固定审批面板显示真实请求标题、详情和项目；拒绝左侧、允许一次右侧；全部提供方选项仍在完整请求面板。拒绝需确认，提交回复后显示等待电脑回执；连接/会话/请求有效性在最终提交前再次核对。
- 项目优先的抽屉，搜索与会话来源/筛选逻辑保留；新对话与设置固定在底部。设置增加清晰标题与连接表单，配置/配对流程保持原协议。
- 文件改动按真实 Git diff 分文件展开，保留分支、统计、增删颜色与原始内容。此接口提供项目当前未提交的改动，不能声称只属于当前任务；未增加假文件计数或任务百分比。

原型到原生的适配：保留顶部画中画入口，使用真实项目与连接数据，不复制样例电脑名、版本号和演示状态。

新建临时 AVD `leoagent-redesign-v2`（Android 34 arm64），专用 `emulator-5562`，数据目录 `/tmp/leoagent-redesign-v2.avd`；现有 `emulator-5554` 保持不动。安装包严格使用 `io.leoagent.app.verification`，测试脚本拒绝普通包或已有验证包。

方向落实阶段保留已有未提交修改，只在其上增量实现；当时没有改版本、签名、服务配置或发布更新。用户随后要求继续，正式候选已单独准备，见文末。

## 验证结果

- Rust 服务构建、Android verification 主包与测试包构建、Android lintDebug、普通 debug 包构建均通过。
- Android 34 专用模拟器上通过两套浅/深色流程：真实触摸发送、HTTP/SSE 回执、允许一次、完整提供方选项、拒绝前确认、服务端已处理审批的清理、语音/文字切换、会话搜索、设置往返与草稿保留、Activity 重建。
- 常规屏幕为 1080×2400 / 420dpi（约 411dp 宽）。窄屏为 840×1920 / 420dpi（320dp 宽），原生审批区完整可见，按钮最小 48dp。
- 320dp 环境额外运行完整隔离集成：请求发出前/发出后回执丢失、401/404、进程终止后恢复，确认使用原操作与请求体且只派发一次 ACP；第二设备处理审批后清理手机等待状态；系统通知允许与拒绝两种分支均通过。
- 文件页通过真实临时 Git 仓库返回 `Review.kt` 的改动；点击按文件折叠并展开后，检查补丁正文实际隐藏与恢复。

[真实截图总览](native/index.html) 提供浅/深色和常规/320dp 切换；截图内英文请求为隔离 fixture，并非用户真实任务。[常规屏幕日志](native-verification.txt)、[320dp 完整日志](native-verification-320dp.txt)、[机器可读记录](native-verification.json)。

验证中修正了测试端两处问题：文件页标题断言仍使用旧文案；坐标检查嵌套调用主线程同步方法导致测试进程退出。正式源码没有因此回退交互目标。截图采集另等待旧链接兼容测试产生的系统 Toast 消失，保留原始像素，不修图。
